発見タブに並ぶ島は、タイトルが似ています。友達に渡す投稿で差がつくのは、コードの位置です。

この順で足ります。

1. 島コード。数字とハイフンを、そのままコピーできる形で
2. 推奨人数と、一周の目安時間
3. 何をする島かを、20字以内で
4. 向いていない人を一言。ホラー、長時間、高難度など

ハッシュタグは最後です。先に付けると、コードが「続きを見る」の向こうに行きます。

自分の島を出す人も、他人の島を紹介する人も、型は同じです。このアカウントが島を紹介するときは、作者の表示名とコードをセットにします。公式のマップであるようには書きません。
